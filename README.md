# Collection Projets de Soutien

Ce repository sert à recueillir les projets de soutien réalisés et nouveaux :

* Les nouveaux projets de soutien peuvent être décrits et enregistrés ici sous forme d'issue
* Avant une assemblée générale, les projets soumis au vote sont marqués avec les tags `grant-20YY` et `voting`
* Après une assemblée générale :
  * les projets acceptés gardent le tag `grant-20YY` et le tag `voting` est retiré
  * les tags des projets refusés sont retirés, mais les projets peuvent rester ouverts
* Les projets de soutien achevés sont `clôturés`, mais restent disponibles
  * Lors de la clôture, merci de laisser un commentaire avec un lien vers le [QGIS Visual Changelog](https://qgis.org/project/visual-changelogs/), la pull request ou similaire
* Les projets de soutien financés autrement ou qui ne sont plus poursuivis sont `clôturés`, mais restent disponibles
  * Lors de la clôture, merci de laisser un commentaire avec un lien vers le [QGIS Visual Changelog](https://qgis.org/project/visual-changelogs/), la pull request ou similaire
* Pour ouvrir un nouveau projet de soutien, sélectionne "New issue" dans le tab "Issues", puis choisis le modèle "Titre du projet de soutien / Titel Förderprojekt". Le modèle fournit une structure de base qui peut être modifiée ou complétée selon les besoins. Les descriptions peuvent également être complétées par des screenshots, des croquis, etc.

 # Sammlung Förderprojekte

Dieses Repository dient der Sammlung von umgesetzten und neuen Förderprojekte:

* Neue Förderprojekte können hier als Issue beschrieben und erfasst werden
* Vor einer Generalversammlung werden die Projekte über welche abgestimmt wird mit den Tags `grant-20YY` und `voting` gekennzeichnet
* Nach einer Generalversammlung:
  * behalten die angenommenen Projekte den Tag `grant-20YY` und der Tag `voting` wird entfernt
  * werden die Tags der abgelehnten Projekten entfernt, die Projekte können aber offen bleiben
* Abgeschlossene Förderprojekte werden `geschlossen` und bleiben erhalten
  * Beim Schliessen bitte einen Kommentar mit einem Link zum [QGIS Visual Changelog](https://qgis.org/project/visual-changelogs/), Pull Request o.Ä. hinterlassen
* Förderprojekte, welche anders finanziert oder nicht mehr weiterverfolgt werden, werden `geschlossen` und bleiben erhalten
  * Beim Schliessen bitte einen Kommentar mit einem Link zum [QGIS Visual Changelog](https://qgis.org/project/visual-changelogs/), Pull Request o.Ä. hinterlassen
* Zum Eröffnen eines neuen Förderprojekts im Reiter "Issues" "New issue" wählen und anschliessend die Vorlage "Titre du projet de soutien / Titel Förderprojekt" auswählen. Die Vorlage gibt eine gewisse Struktur vor, welche je nach Bedarf gerne abgeändert oder erweitert werden kann. Gerne dürfen die Beschreibungen auch mit Screenshots, Skizzen etc. ergänzt werden.
